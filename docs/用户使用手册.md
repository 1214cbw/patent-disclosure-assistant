# 专利技术交底书智能生成器 — 用户使用手册

本手册面向科研人员、工程师和学生。目标是：**把自己的论文或技术资料快速整理成可以交给专利代理机构的中文技术交底书。**

---

## 一、如何启动

双击项目根目录的 `start_patent_agent.bat`。

服务就绪后浏览器自动打开 `http://127.0.0.1:8765`。

首页标题应为"专利技术交底书智能生成器"。

---

## 二、如何关闭

双击 `stop_patent_agent.bat`。

不要在生成过程中强制关闭；若意外中断，按第九节恢复。

---

## 三、新建技术交底书

1. 在首页点击 **"新建技术交底书"**。
2. 填写项目名称（可选，留空将自动生成）。
3. 填写项目编号（可选）。
4. 上传材料：点击选择文件或拖拽上传。支持：
   - PDF（论文、报告）
   - DOCX（Word 文档）
   - PPTX（PowerPoint 演示文稿）
   - TXT / MD（纯文本、Markdown）
   - PNG / JPG（图片、示意图）
   - 单文件上限 50MB
5. 可选：填写补充说明。如有希望重点描述的技术创新、项目背景，可以在此注明。
6. 确认 AI 模型状态显示"已连接"。
7. 点击 **"开始生成技术交底书"**。

---

## 四、生成过程

点击开始后，系统会自动完成以下步骤：

| 用户看到的阶段 | 内部处理 |
|---|---|
| 正在读取材料…… | 文件解析、文本提取、Evidence 建库 |
| 正在提取技术内容…… | 关键段落识别、公式提取、图表识别 |
| 正在理解技术方案…… | AI 分析技术事实、步骤、模块关系 |
| 正在生成中文技术交底书…… | 撰写完整中文交底书各章节 |
| 正在生成公式和附图…… | OMML 公式渲染、专利风格附图 |
| 正在生成 Word…… | 排版、样式、DOCX 输出 |
| 正在检查文档…… | 中文化检查、Word 兼容性验证 |

用户只需要等待进度条完成即可。

---

## 五、一键确认

AI 分析完成后，系统会显示技术分析摘要：

```
识别到：
22项关键技术事实
5个主要技术步骤
3个技术模块
1个关键公式
2个建议附图
7个待确认事项
```

点击 **"一键审核通过并生成交底书"**。

然后系统会继续生成完整的中文技术交底书并导出 Word。

> 内部审计记录为"整体确认（BATCH_APPROVED）"，不会伪造逐条人工审核记录。

如果需要查看详细的技术事实列表，可以点击"查看详细分析"展开。

---

## 六、下载技术交底书

交底书生成完成后，页面会显示预览。

点击 **"下载技术交底书"** 即可获得 `技术交底书.docx`。

文件中包含以下章节：
1. 发明名称
2. 技术领域
3. 背景技术
4. 现有技术存在的问题
5. 发明目的
6. 技术方案
7. 有益效果
8. 附图说明
9. 具体实施方式
10. 技术关键点及建议重点关注内容
11. 待发明人或代理机构进一步确认的事项

---

## 七、如何重新生成

如果对结果不满意：

1. 点击 **"重新生成"** 按钮。
2. 系统将重新执行整个生成流程。

也可以：
1. 点击 **"修改内容"** 按钮对特定章节进行修改。
2. 在项目详情页调整材料后重新生成。

---

## 八、中断后如何恢复

如果生成过程中关闭了页面或服务意外停止：

1. 重新双击 `start_patent_agent.bat`。
2. 首页会显示未完成的项目。
3. 点击项目名称进入详情。
4. 系统会自动检测进度，并提示"继续生成"。

---

## 九、DeepSeek 配置

AI 模型使用 DeepSeek。配置由管理员在项目根目录 `.env` 文件中设置：

```dotenv
LLM_PROVIDER=openai-compatible
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=your-deepseek-api-key
LLM_MODEL=deepseek-v4-pro
PATENT_LLM_MODE=external-approved
APP_MODE=disclosure_only
```

普通用户不需要修改这些配置。

在网页"设置"中可以查看 AI 连接状态。

---

## 十、数据和隐私

- 服务只监听本机地址 `127.0.0.1`，不会对局域网或公网开放。
- 上传的材料保存在本地 `workspace/private_cases/` 目录中。
- 调用 DeepSeek API 时仅发送必要的技术内容（Evidence chunks），不上传完整文件。
- `.env` 中的 API Key 不会被提交到 Git。
- 生成的技术交底书保存在本地，不会上传到任何云端。

---

## 十一、常见问题

**Q: 必须上传英文论文吗？能处理中文材料吗？**
A: 都可以。无论输入是中文还是英文，最终输出的技术交底书都是简体中文。

**Q: AI 会不会编造内容？**
A: 系统有严格的 Evidence 约束机制。每个技术事实必须关联到材料中的具体依据。不会补充材料中不存在的数据、参数或实验结果。

**Q: 生成的技术交底书还需要修改吗？**
A: 建议快速浏览一遍，确认技术描述准确。如果发现问题，可以在网页上修改或重新生成。交底书的"待确认事项"章节会列出 AI 认为需要进一步确认的内容。

**Q: 生成一份交底书需要多长时间？**
A: 取决于材料长度和 AI 响应速度。通常几分钟到十几分钟。

**Q: 交底书能直接提交专利申请吗？**
A: 不能。技术交底书是给专利代理机构的工作文件，代理师会在此基础上撰写正式的专利申请文件。

**Q: 如何确保我的技术内容安全？**
A: 系统本地运行，不对公网开放。API Key 和真实材料都在 `.gitignore` 中排除。如需更高安全级别，可以在完全离线环境使用 deterministic 模式（不调用外部 LLM）。
