# 技术领域

电机状态监测、故障预警与自适应控制，涉及多源传感信息同步、状态融合和闭环控制。

# 技术背景

- 现有电机控制器通常以定子电流和转速作为主要反馈量。
- 独立的振动监测设备可用于机械故障检测，但检测结果通常不直接参与控制参数修正。
- 温度保护一般采用固定阈值，难以描述负载变化下的连续热状态。

# 现有技术存在的问题

- 单一电流或转速反馈难以同时反映电气、机械和热状态。
- 多类传感器的采样时钟和噪声水平不同，直接拼接可能导致状态估计不稳定。
- 状态监测与控制回路相互独立，检测结果不能及时转化为控制参数修正量。

# 技术问题

如何在不依赖单一传感源的情况下获得可用于闭环控制的电机融合状态量，并根据该融合状态量在线生成自适应控制指令。

# 系统组成

- 状态采集单元：采集振动、定子电流、转速和温度信号。
- 时间同步单元：将不同采样频率的信号映射到统一时间窗。
- 状态估计单元：计算传感信号置信度并形成融合状态量。
- 控制处理单元：根据目标状态与融合状态量的偏差更新控制参数。
- 电机驱动单元：依据自适应控制指令驱动电机。

# 算法流程

- 获取振动、定子电流、转速和温度信号。
- 对多源信号进行时间同步和归一化，形成多源特征向量。
- 根据各信号的质量指标计算置信度权重，并得到融合状态量。
- 计算目标状态与融合状态量之间的状态偏差。
- 根据状态偏差和历史偏差生成自适应控制指令并输出至电机驱动单元。

FORMULA EQ-001 | 多源状态融合 | z_k=\alpha x_{v,k}+\beta x_{i,k}+(1-\alpha-\beta)x_{T,k}

FORMULA EQ-002 | 状态偏差计算 | e_k=r_k-z_k

FORMULA EQ-003 | 自适应控制更新 | u_k=u_{k-1}+K_pe_k+K_i\sum_{j=1}^{k}e_j

FORMULA EQ-004 | 电磁转矩估计 | T_e=\frac{3}{2}p[\psi_f i_q+(L_d-L_q)i_di_q]

SYMBOL z=融合状态量
SYMBOL k=离散时间序号
SYMBOL \alpha=振动特征权重
SYMBOL \beta=电流特征权重
SYMBOL x=归一化传感特征
SYMBOL v=振动通道标识
SYMBOL i=电流通道标识
SYMBOL T=温度通道标识
SYMBOL e=状态偏差
SYMBOL r=目标状态
SYMBOL u=控制指令
SYMBOL K_p=比例修正系数
SYMBOL K_i=积分修正系数
SYMBOL j=累计序号
SYMBOL T_e=电磁转矩
SYMBOL L_d=d轴电感
SYMBOL L_q=q轴电感

# 技术效果

- 将机械、电气和热状态映射为同一融合状态量，为闭环控制提供统一输入。
- 通过置信度权重降低单个传感通道异常对控制指令的影响。
- 使状态监测结果能够直接参与控制参数修正，缩短监测与控制之间的信息链路。

# 合成演示实验

SYNTHETIC DEMO DATA：在人工构造的传感噪声场景下，与等权融合演示基线相比，状态估计均方误差由0.082降至0.061；该数值仅用于测试证据标记、表述和校验，不得作为真实实验结果或申请事实。

# 可替代实施方式

- 状态采集单元可仅使用振动、电流和温度中的两种信号。
- 置信度权重可由信噪比、缺失率或传感器自检状态确定。
- 控制处理单元可采用PI控制、模型预测控制或其他有来源支持的控制方式。
